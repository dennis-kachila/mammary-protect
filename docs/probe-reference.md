# Probe reference and design targets

An earlier local probe design sheet recorded the following approximate external dimensions for a candidate angled ultrasound probe. These numbers are for packaging exploration and require caliper verification on the actual part.

| Feature | Reference dimension |
| --- | ---: |
| Sensing face | 14.5 mm |
| Tip outside diameter | 15.8 mm |
| Grip outside diameter | 17.8 mm |
| Tip length | 14 mm |
| Head length | 26.5 mm |

The holder model explores a perpendicular cable outlet relative to the probe head. The fit at the joint was adjusted visually. The next holder revision should be driven by measured probe geometry and a physical clearance test. Two proposed docking magnets are 3 mm diameter by 5 mm high, with a 30.5 mm center-to-center target spacing.

The original design sheet contains a third-party product photograph, so its dimensions are summarized here without redistributing the photograph.
